# Step: inventory brownfield contract surfaces

Consume the exact `target_identity`. Run deterministic repository inventory before broad reading, then start one `contract_bootstrap_state` session bound to the same literal HEAD.

Map bounded components and likely contract-bearing surfaces: public entry points, architecture/ownership boundaries, CLI/API/config/schema surfaces, persistence and migrations, lifecycle behavior, tests/CI, compatibility/deprecation promises, and operator-visible behavior.

Do not require an existing `docs/protected-capabilities.json`; this Playbook exists specifically for repositories where that registry is absent or incomplete.

Return only `bootstrap_inventory`: bootstrap ID, exact target SHA, bounded component list, candidate evidence roots, and explicit uninspected areas.
