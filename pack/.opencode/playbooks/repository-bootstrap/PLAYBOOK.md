# Repository Bootstrap Playbook

Bootstraps an initially unknown folder or codebase into verified repository identity, inventory, authority, architecture, risk, and a durable discovery report. Use `/playbook repository-bootstrap`.

`PROMPT.verbatim.md` preserves the exact original bootstrap prompt byte-for-byte. The executable workflow decomposes that source into bounded Steps so it obeys the accepted on-demand materialization contract instead of loading a 323-line Step at once.
