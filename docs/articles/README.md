# Engineering articles

This directory contains explanatory and long-form engineering material related to CodeSleuth.

Articles are **non-normative**. They may explain the motivation, history, examples, or broader engineering context behind an accepted CodeSleuth contract, but they do not override canonical product, architecture, lifecycle, security, or integration documents.

When an article and a canonical contract appear to disagree, the canonical contract and executable acceptance tests are authoritative.
