# RC6 Archive

This directory contains superseded RC6 planning and design-evidence documents retained for historical traceability.

Archived documents are **not current authority**. Current RC6 authority/state lives in:

- `docs/RC6-FEATURE-PLAN.md`
- `docs/RC6-SCOPE-ACCEPTANCE.md`
- `docs/RC6-IMPLEMENTATION-LEDGER.md`

Archive rules:

- preserve historical content rather than rewriting it into current truth;
- do not use archived implementation order as a live queue;
- follow redirect stubs in `docs/` when an older path is referenced;
- exact historical SHAs/runs remain evidence only for the state they described.
